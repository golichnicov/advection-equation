\# Численное моделирование линейного уравнения переноса 

\## Описание проекта

Исследование численных схем решения гиперболического уравнения переноса:

\* \*\*Upwind\*\* (схема против потока, 1-й порядок);

\* \*\*FTCS\*\* (наивная центрально-разностная схема, неустойчивая);

\* \*\*Lax\*\* (схема Лакса, 1-й порядок);

\* \*\*Lax-Wendroff\*\* (схема Лакса–Вендроффа, 2-й порядок).
